# コンボ・リコール（`combo-recall`）

位置 n-back（single n-back）のミニゲーム。仕様書 第6.2節の本実装（フェーズ2）。
光った「攻撃位置」が n 個前と同じなら「攻撃」を押し、違えば押さない。n はラウンドごとの誤りの数でアルゴリズムが決める。

**1試合 = (20 + n) 試行 × 1 ラウンド**（仕様書 v1.2。「ダブルヒットとコンボ・リコールも1ラウンドでいい」というユーザーのフィードバックで、
3 ラウンド＋任意の「もう1ラウンド」（約 3〜4 分）から約 1 分に短縮した）。「もう1ラウンド」は廃止（`extraRounds: 0`。1 ラウンドの試合の
「一本勝負」表示と矛盾するため）。認定戦は今までどおり 2 ラウンド（`src/cert/` の `CERT_ROUNDS`。訓練の `roundsPerMatch` とは別）。

## 仕様（6.2）との対応

- **画面**: 刺激領域に 3×3 のマス。中央に敵のシルエット、まわりの 8 マスが敵の「攻撃位置」。1 試行に 1 マスが 500 ms 光る（明るい塗り＋打撃マークの形。色だけに頼らない）。下帯の応答ボタンは「攻撃」1つ。
- **試行**: `stimulus` 500 ms → `response`（消灯）2,000 ms。両方 `input: true` で 1 つの応答窓（2.5 秒ずっと押せる）。`untilResponse` は使わない固定タイミングなので、押しても次の刺激の時刻は変わらない。反応時間は点灯の開始から（エンジンが `stimulus` の開始から測る）。
- **正解**: 標的（n 個前と同じ位置）で押す＝ヒット。標的で押さない＝見逃し（`miss`）。非標的で押さない＝正答（`expectedResponse` は `null`）。非標的で押す＝誤警報（`fa`）。
- **系列**（`nback.ts`）: 1 ラウンド 20 + n 試行、標的ちょうど 6 個。n ≥ 3 はルアー（n−1 個前か n+1 個前と同じで、n 個前とは違う）を試行数の 10〜15%。同じマスの連続は 2 回まで。乱数は `createRound` の `rng` だけ。
- **適応**（ラウンド単位）: 誤り = 見逃し + 誤警報。`nbackStep`（`staircase.ts`）で < 3 → n+1、> 5 → n−1、他は維持、1〜9。初期 n = 1、2 試合目以降は保存された n（`restoreParams` で 1〜9 の整数にそろえる）。
- **戦闘力**: K = 9、L = n、`acc = 1 − 誤り/(20+n)`、`accDown = 1 − 5/(20+n)`、`accUp = 1 − 2/(20+n)` を `power.ts` の `blockPower` に渡す。結果は n と誤りの数だけで決まる（誤り ≤ 2 で sub = 1、3 で 2/3、4 で 1/3、≥ 5 で 0）。反応時間は使わない。
- **ラウンド**: 1 試合 1 ラウンド（`roundsPerMatch: 1`・`extraRounds: 0`。v1.1 までは 3 ラウンド＋「もう1ラウンド」1 回）。長さは n = 1 で 52.5 秒、n = 9 で 72.5 秒。
  n はラウンド末に決まるので、1 試合で最大 ±1 動き、次の試合はその n から（保存された state）。
- **PC キー**: スペース＝攻撃（`' '` と `'Space'`）。
- **ルールの一言**（`roundIntro`）: 「n 個前と同じ位置なら攻撃。違えば押さない」（n は数字）。1 試合 1 ラウンドなので、出るのは開始前の画面だけ。
- **ラウンド末の一言**（`roundTip`）: 誤りの内訳で選ぶ（方略・努力向け。能力ラベルなし。1 ラウンドの試合では結果画面に出る。ラウンド番号には依らない）。誤り 0 → ノーミス、1〜2 → ペース維持、3 以上で「ルアーへの誤警報が 2 回以上かつ誤警報の半分以上」→ 何個前かを数え直す、見逃し > 誤警報 → 位置を心の中で言い直す、誤警報 > 見逃し → 迷ったら押さない、同数 → 落ち着いて照合。
- **認定戦**: `certParams(tier)` = `{ n: tier }`（1〜9）。`untrained: true` では盤を円周上の 8 点に差し替える（判定・系列の作り方は同じ）。合格は 1 ラウンドの誤り 4 以下（`certRoundPassed`）。
- **表層バリエーション**（`surfaceCount = 3`）: 0 夜の道場（角丸の四角・構え）、1 夕暮れ（円・低い構え）、2 竹林（ひし形・腕を広げた構え）。変えるのはマスの形と色・敵のシルエット・背景色だけで、時間・試行列は変わらない。

### 記録（`metrics`）

| キー | 意味 |
|---|---|
| `n` | そのラウンドを戦った n |
| `targets` / `lures` | 標的の数（6）／ルアーの数 |
| `hits` / `misses` | ヒット／見逃し |
| `falseAlarms` | 誤警報（非標的で押した。ルアーへの誤警報も含む） |
| `lureFalseAlarms` | そのうちルアーへの誤警報（別集計） |
| `correctRejections` | 正しく押さなかった非標的 |
| `errors` | 誤り = 見逃し + 誤警報（適応に使う数） |
| `dPrime` | d′（`stats.ts` の `dPrime`。ヒット率・誤警報率に log-linear 補正。小数 2 桁） |
| `rtMedianMs` | ヒットの反応時間の中央値（記録用だけ。ヒットが無ければ出さない） |

`RoundRecord.errors`（判定の `kind` の集計）は `miss` と `fa` の 2 種。
試行ログの `stim` は `g3*`（訓練の盤・位置 3・標的）、`r5~`（認定戦の円周・位置 5・ルアー）、`g0`（どちらでもない）の形。

## 仕様書と違えた点・解釈した点

1. **攻撃位置は 8 つ**（3×3 の中央は敵の立ち位置で光らない）。n-back の標準形（Jaeggi 2008: 3×3 の盤の中央を除く 8 マス）に合わせ、認定戦の「円周上の 8 点」と位置の数をそろえた（偶然の一致率が訓練と認定戦で同じ 1/8）。
2. **認定戦の円周 8 点は 22.5° ずらして置く**（訓練の上下左右・斜めの方向と重ならない位置にして「未訓練の位置」にする）。中央は注視用の小さな円だけで、敵は描かない（演出最小）。
3. **ルアーの数**は「試行数 × 12.5% を丸め、10〜15% の範囲に収める」: n = 3〜7 で 3 個（11.1〜13.0%）、n = 8・9 で 4 個（14.3%・13.8%）。n ≥ 3 のルアー以外の試行は n±1 個前とも一致させない（偶然の一致でルアーが 10〜15% を超えないように）。
4. **n ≤ 2 はルアーを意図して入れない**（仕様どおり。偶然の n±1 一致は制限しない）。ただし試行の `lure` と `lureFalseAlarms` は n によらず「n±1 個前と同じで n 個前とは違う」で数える（n = 1 は 0 個前を数えないので 2 個前だけ）。n ≤ 2 の値は偶然の一致の記録。
5. **「標的の位置が偏らない」**は時間と空間の両方で満たす: 標的を置ける 20 試行（n 番目以降）を前・中・後に 3 分割して 2 個ずつ（7・7・6 試行の区間）、標的のマスは 6 個とも別のマス（8 マスから）。このため同じマスの標的の連鎖（i と i−n の両方が標的）は作らない（n = 1 では同じマスが 3 連続になるのを避けることにもなる）。どの区間のどの試行が標的になるかは毎回ランダム。
6. **誤答の内訳**は `miss` / `fa` の 2 種。ルアーへの誤警報は `fa` に含めたうえで `metrics.lureFalseAlarms` に別に数える。
7. **戦闘力でラウンドがまだ無い**（`lastRound = null`）ときは sub = 0（到達した n の分だけ）。
8. **認定戦で n を変えない**: 認定戦の実行側（`adaptive: false` で動かし、ラウンド単位の `adapt` を呼ばない）に加え、`adapt` 自身も円周（未訓練セット）のラウンドでは n をそのまま返す（二重の安全策）。
9. **試行ごとの 1 ビットフィードバック**: 押した試行（ヒット・誤警報）は押した瞬間に判定され、上帯に出る。押さなかった試行（見逃し・正しい見送り）は、応答窓（2.5 秒）が閉じる瞬間＝次の点灯と同じフレームで判定されるため、上帯の表示は出ない（HUD は残り時間 0 では出さない）。仕様の「2.5 秒ずっと応答可」を優先した結果（効果音については親への報告を参照）。
10. **ラウンドの長さ**: 仕様の数値（20 + n 試行 × 2.5 秒）どおりにすると n = 1 で 52.5 秒（仕様書の「約 55〜75 秒」の下端より少し短い）。数値は変えていない。
11. **敵のシルエットは盤の一部**として、このゲームが刺激領域の中に描く（どの演出プリセットでも同じ、ラウンド中は動かない・変わらない静止画）。`skin/fighter.ts` は使わず、`board.ts` の単純な図形（実在のキャラを模さない）で描く（演出層の変更で刺激の見た目が変わらないように）。
12. **盤面のタップ**（`hitTest`）は実装しない。応答は下帯の「攻撃」ボタンとスペースキーだけ（仕様の「応答ボタンは攻撃 1 つ」）。

## 後続（MVP 外）

- 位置＋音の dual n-back（仕様書 6.2「後続」: n ≥ 3 が 3 試合安定したら解放。音は 8 種の短い打撃音）。MVP では実装しない。
- 天井対策（仕様書 4.3: 最上位レベルで 3 試合連続 80% 以上なら次の難度軸）の具体化は、dual n-back の解放と合わせて後続で決める。
